# 用户使用手册

## 它会做什么

Mac 磁盘扫描助手会统计你所选目录的大小、实际占用、修改时间和目录结构，然后在本机告诉你：空间去了哪里，这些内容大概是什么，以及可以去哪里进一步核对。

它不会：

- 打开或分析文件内容；
- 删除、移动或修改扫描到的文件；
- 自动执行终端命令；
- 使用管理员权限；
- 上传路径、文件名或统计数据。

## 第一次扫描

1. 打开应用，点击“选择目录”。
2. 第一次使用时，建议选择你的个人文件夹，先不要扫描整块硬盘。
3. 扫描过程中可以查看进度，也可以随时取消。
4. 扫描结束后，先到“访问问题”看看有没有未能读取的目录。
5. 在“占用排行”中选择一个项目，查看它的用途、判断依据和处理建议。
6. 确认内容来源、用途和备份后，再到访达、相关应用或终端中自行处理。

扫描完成后，概览页会显示两个操作：

- **重新扫描**：再次扫描刚才选择的目录；
- **选择其他目录**：打开系统目录选择器，开始新的扫描。

扫描过程中，窗口右上角会明确显示“正在扫描”和“取消”。点击取消后可以选择：

- **查看当前结果**：停止继续扫描，并把已经完成的部分标记为“不完整结果”后展示；
- **放弃结果**：停止扫描并丢弃本次临时结果。

任何选择都不会删除或修改文件。

## 未签名社区版本如何打开

官网下载的社区版本没有 Apple Developer ID 签名和公证，macOS 第一次打开时可能会拦截。请先核对下载网站和 SHA-256 校验值，再前往“系统设置 → 隐私与安全性”，在安全提示旁选择“仍要打开”。

不要为了安装本应用而关闭整台 Mac 的安全检查。

## 为什么全盘扫描很慢

扫描速度主要取决于文件数量，而不是磁盘容量。一个装着几十万张小图片的目录，往往比一个几百 GiB 的单文件更慢，因为应用必须逐个读取文件大小等信息。

扫描整块硬盘时，数百万个文件仍可能需要很长时间。休眠中的外置硬盘、系统权限检查和大量小文件都会拖慢速度。优先扫描个人文件夹或已经怀疑的目录，通常更快找到问题。

为了避免问题记录本身占用太多内存，应用最多保留 5,000 条明细。超出部分仍会计数，并在界面中说明省略了多少条。

## 频繁扫描会伤硬盘吗

正常频率的只读扫描不会对 Mac 的 SSD 造成可感知损伤。SSD 耐久度主要由写入和擦除次数决定；本应用主要枚举目录，并读取大小、日期等文件系统元数据，不打开文件内容。

扫描仍会暂时占用 CPU、磁盘带宽和电量，也可能让机器短时间升温。无需定时或连续反复全盘扫描；通常只在空间明显变化时扫描一次，之后针对个人文件夹或可疑目录复查即可。

## 如何理解空间数字

- **逻辑大小**：文件对外显示的大小。
- **已分配空间**：文件系统实际为它分配的空间，通常更接近磁盘占用。
- **可能可释放**：值得继续核对的大小，不保证最后一定能腾出这么多空间。
- **共享磁盘块**：APFS 可以让多个文件共用同一部分磁盘空间，所以简单相加可能偏大。
- **稀疏文件**：看起来很大，但实际只占用了其中一小部分空间。

## 如何理解访问问题

“无法读取”不等于“不占空间”。“邮件”“信息”、Safari、其他 App 容器和部分系统目录受 macOS 保护。Mac 磁盘扫描助手默认跳过这些范围，或把系统拒绝的位置列出来，不会假装扫描已经完整。

“其他 App 数据”默认关闭。只有你在“设置 → 受保护目录”中主动开启，或直接选择某个 App 容器进行一次性扫描时，macOS 才可能询问授权。拒绝不会中断其他目录的扫描。

## 命令建议

应用只能提供事先写入程序的固定命令。点击后只是复制到剪贴板，不会自动运行。执行前请：

1. 阅读完整命令；
2. 确认它属于目标工具；
3. 先运行检查命令；
4. 确认备份和退出目标应用；
5. 再由你自己决定是否在终端执行。

## 常见问题

### 为什么显示 0 B？

零表示文件系统报告当前没有已分配块，例如空文件。小于 1 KB 的非零值会按字节显示，不再舍入成 `zero KB`。

### 为什么“可能可释放”和最后腾出的空间不同？

有些文件会共享磁盘空间，有些正在被应用使用，清理后应用也可能马上重新生成缓存。因此，这个数字只用于判断先检查哪里。

### 为什么不提供一键清理？

相同目录名在不同应用、版本和账户中可能代表完全不同的数据。一键操作会把分类误差直接变成数据损失，因此不属于本项目目标。
