# 0.2.0 RC3 验收记录

日期：2026-07-24

## 本轮重点

- 修复“占用排行”切换排序后变化不明显的问题；
- 将排序算法移入可独立测试的扫描核心；
- 类型和风险排序增加分组标题；
- 排序说明直接显示在列表上方；
- 切换排序时不再重复计算与排序无关的建议列表；
- 隐藏最外层目录后，右侧详情会自动选择列表中的第一项。

## 自动验证

- `swift test`：21 项测试通过；
- 大小排序：按占用空间降序，相同大小按路径稳定排序；
- 类型排序：按类型分组，组内按大小降序；
- 风险排序：禁止手动处理、高风险、需确认、低风险依次显示，组内按大小降序；
- `Scripts/check-source-safety.sh`：通过。

## 真实界面验证

使用项目内生成的 15 MiB 测试夹具，包含：

- 普通文档；
- `Library/Caches`；
- npm `_cacache`；
- Antigravity `browser_recordings`；
- Cursor `state.vscdb`。

扫描后逐一点击“大小”“类型”“风险”：

- 大小模式显示“从大到小”；
- 类型模式显示“异常数据”“应用内可管理数据”“可重新生成缓存”“未知数据”等分组；
- 风险模式显示“高风险”“需确认”“低风险”等分组；
- 每次切换后，顶部说明和列表分组均同步变化。

测试夹具位于被 Git 忽略的 `build/ui-sort-fixture`，不包含任何真实用户数据。
