# 0.2.0 RC5 Liquid Glass 验收记录

日期：2026-07-24

## 本轮目标

RC4 已使用真正的 SwiftUI Liquid Glass API，但玻璃只出现在少量按钮上，窗口背景又接近纯色，因此实际观感仍像普通深色 SwiftUI App。RC5 的目标是建立可感知的空间层级，而不是简单增加透明卡片数量。

## 设计实现

- 窗口内容区使用低饱和、静态的青绿与暖橙环境色，给玻璃提供可折射的背景；
- 扫描状态、当前范围和主要操作合并为顶部悬浮功能层；
- 侧栏隐私声明使用独立玻璃层，持续提醒本地、只读边界；
- 排序器使用 `GlassEffectContainer`、`glassEffectID` 和 matched glass transition；
- 长文本、容量图表和扫描证据继续使用稳定的内容表面，避免降低可读性；
- macOS 13–15 回退到系统 Material，macOS 26 使用原生 Glass API；
- “减少动态效果”使用短淡入淡出，“降低透明度”关闭环境色。

## 实机验收

环境：macOS 26、Xcode 26.5 Debug `.app`。

仅扫描项目内 `build/ui-sort-fixture`，未扫描工作区外用户数据：

- 空状态顶部玻璃层可见，主操作、只读说明和路径说明层级清楚；
- 扫描完成后顶部层稳定显示扫描根目录，没有随进度路径改变宽度；
- 概览页容量、指标和柱状图可读；
- 占用排行保持列表与详情双栏结构；
- 从“大小”切换到“类型”后，选中玻璃移动，列表按类别重新分组；
- 使用说明卡片保持等宽，中文说明完整显示；
- 删除了标题栏中重复的选择目录入口。
