- 社区包使用 ad-hoc 签名，没有 Apple Developer ID 签名和公证；
- 首次打开可能需要在“系统设置 → 隐私与安全性”中选择“仍要打开”；
- 不应把当前版本宣传为“一键清理”或保证释放某个固定空间；
- 正式公开 Release 前，仍建议在另一台 Mac 或全新本地账号上完成一次安装验收。
