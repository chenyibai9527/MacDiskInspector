# 0.2.0 RC4 Liquid Glass 验收记录

日期：2026-07-24

## 设计边界

- Liquid Glass 只用于导航、主要操作、排序控件和临时状态等功能层；
- 数据卡片与长文本内容继续使用高对比度标准表面；
- 不用玻璃装饰代替风险、分类或扫描状态的信息层级；
- 保留系统“降低透明度”“增强对比度”等辅助功能的自适应行为。

## 系统适配

- macOS 26 及以上：使用 `glassEffect`、`GlassEffectContainer`、`.glass` 和 `.glassProminent`；
- macOS 13–15：通过可用性分支回退到 `.thickMaterial`、`.bordered` 和 `.borderedProminent`；
- App 最低运行版本仍为 macOS 13；
- 从源码构建需要 Xcode 26 或更新版本。

## 真实界面验证

在 macOS 26 上启动 Debug `.app`，使用项目内 15 MiB 测试夹具完成只读扫描：

- 空状态主要操作呈现系统玻璃按钮；
- 工具栏保持系统原生 Liquid Glass；
- 占用排行显示“大小”“类型”“风险”三个独立玻璃按钮；
- 当前排序项使用突出玻璃样式并具有无障碍选中状态；
- 连续切换类型和风险后，分组、排序说明与右侧详情保持正确；
- 内容列表和详情区未被过度透明化，文字对比度稳定。
