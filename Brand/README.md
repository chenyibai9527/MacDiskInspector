# Brand assets

## Visual direction

The mark combines a storage volume with inspection rings. It communicates
diagnosis and visibility rather than automatic cleanup.

- Warm stone background
- Graphite and charcoal hardware
- One restrained amber status accent
- No blue-purple gradient, cleanup metaphor, warning symbol, or marketing text

## Files

- `MacDiskInspector-Mark-Source.png`: original generated source.
- `MacDiskInspector-Mark-1024.png`: normalized 1024 × 1024 master.
- `App/Assets.xcassets/AppIcon.appiconset`: Xcode-generated size set.
- `Distribution/Installer-Background-ImageGen.png`: source artwork for the
  DMG Finder background and visible installation guide.
- `Distribution/DMG-Icon-Chroma-ImageGen.png`: original installer-volume icon
  generation with a removable chroma background.
- `Distribution/DMG-Icon-Transparent.png`: transparent source used to generate
  the mounted volume `.icns`.

The distribution artwork was generated with the built-in ImageGen tool. The
installer background prompt requested a quiet, premium macOS utility surface
with warm stone, graphite scan rings, restrained amber details, generous empty
space, and no rendered text. The volume-icon prompt requested a ceramic
external-drive form with a subtle download/document motif, the same material
palette, no letters, and a flat chroma background for clean removal.

The generated raster artwork should be reviewed for trademark conflicts before
large-scale commercial promotion. Keep the product name as live text rather
than baking it into the icon.
