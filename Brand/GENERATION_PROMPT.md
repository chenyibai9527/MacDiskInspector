# App icon generation prompt

Use case: logo-brand

Asset type: native macOS utility app icon, master 1024x1024

Create a premium, calm, trustworthy icon for an explainable read-only Mac disk
inspector. Combine a simplified hard-drive volume with subtle concentric
inspection rings or a precise scanning aperture, communicating diagnosis and
visibility rather than cleanup.

Use a polished, vector-friendly geometric 3D macOS icon style with restrained
depth and a strong small-size silhouette. Center one symbol inside a softly
rounded-square tile with generous internal padding.

Palette: warm off-white and light stone background, graphite and charcoal disk
symbol, and one tiny muted amber status accent. Use subtle matte ceramic and
anodized-metal materials with a minimal soft shadow.

No text, letters, numbers, watermark, transparency, blue-purple gradients,
rainbow or neon colors, glossy gaming styling, broom, trash can, rocket,
speedometer, pie chart, warning triangle, Apple logo, Finder face,
photorealistic hardware, or busy tiny details.
